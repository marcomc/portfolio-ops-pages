Portfolio Ops is a private portfolio coordination tool that runs on its owner's Mac. It helps organize authorized project work and prepare reports from selected sources.

How data is used →

How it works

A small, owner-operated workflow.

01

Selected sources

The owner chooses and authorizes the sources used to prepare portfolio information.

02

Owner-controlled operation

The application runs on the owner's Mac with protected local credentials and storage. Authorized reports use Google delivery; owner-authorized agent workflows may process selected context through external services.

03

Private reporting

Reports can be sent to an existing authorized recipient. The application is for personal use, not a public service.

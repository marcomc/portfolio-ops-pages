## Publishing

GitHub Pages serves the repository root from `main` over HTTPS at
<https://portfolio-ops.marcomc.com/>. `CNAME` declares the dedicated domain;
`.nojekyll` keeps these files unchanged. Publication and live delivery must be
verified before using the URLs in OAuth branding.

## Scope

No application source, portfolio records, private configuration, OAuth clients,
credentials or operational evidence belong in this repository. The site has
no forms, scripts, analytics, external fonts or public app signup.
